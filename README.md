# Букет

Маленькая одностраничная открытка с виртуальным букетом. React + Vite, без бэкенда.

## Запуск

```bash
npm install
npm run dev        # локально, http://localhost:5173
npm run build      # статика в папке dist/
```

`dist/` можно выложить на любой статический хостинг (Netlify, Vercel, GitHub Pages, Cloudflare Pages).
Пути относительные, поэтому страница работает и из подпапки.

## Как поменять текст

Всё в `src/config.json`:

- `intro`, `introButton` — первый экран;
- `message` — строки под букетом;
- `signature`, `date`, `ps` — подпись, дата и шутка про кошку;
- `timing` — через сколько появляется текст и P.S.;
- `flowers[].initialCount` — сколько цветов каждого вида в букете сразу;
- `bouquet.slots` — где стоит каждый цветок (угол стебля, высота, слой).
  Первые `initialCount` мест заняты с самого начала, остальные — для кнопки «Добавить цветок».

## Цветы

Изображения лежат в `public/flowers/` (WebP с прозрачным фоном).
Их размеры и точки крепления стебля описаны в `src/data/assets.json` — этот файл сгенерирован
вместе с картинками, руками его менять не нужно.

Картинки цветов отрендерены процедурно в Blender (Python-модуль `bpy`), скрипты — в `tools/flower-render/`.
Если захочешь заменить их фотографиями, положи PNG/WebP с прозрачным фоном в `public/flowers/`
и поправь размеры и точки стебля в `src/data/assets.json`.
